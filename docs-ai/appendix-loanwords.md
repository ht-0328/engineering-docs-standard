# 付録 横文字の扱い

**この付録は、AIの話に出てくる横文字を、言い換えるか残すかの判断を記録する。**

## この付録が必要な理由

本編は「平易な語で書く」ことを求めている。**AIの話は横文字だらけである。** そのまま書けば読みにくく、無理に言い換えれば別の問題が起きる。

**その別の問題とは、`AD-05`（用語を統一し、読み手が使う語で書く）に反することである。**

## 言い換えると何が起きるか

査読つきの研究 NoLiMa は、**語句がそのまま一致する手がかりを消すと、成績が急落する**ことを示している。32,000トークンでは13モデル中11モデルが、短い入力での成績の半分を下回った。

**これは、独自の言い換えを作ることの費用である。**

たとえば「プロンプト」を「指示文」と言い換えたとする。

| 起きること | 内容 |
|---|---|
| 人にとって | 平易になる。**良いこと** |
| 検索にとって | 「プロンプト」で探す人と、AIが、この文書に当たらなくなる |
| 他の文書との関係 | 引用する外部の文書はすべて「プロンプト」と書いている。**対応が取れなくなる** |

**「読みやすさ」と「見つけてもらいやすさ」がぶつかる。**

## 判断の基準

**次の3つで決める。**

| 問い | 「はい」なら |
|---|---|
| 1. その語で検索されるか | **残す** |
| 2. 定着した日本語訳があるか | **訳を使う** |
| 3. どちらでもないか | **平易な日本語にする** |

そして、**残すと決めた語には、初出のときに短い説明を添える。**

## 残す語

<!-- doclint-disable term_consistency -->

**検索される語である。言い換えない。**

| 語 | 理由 | 初出で添える説明 |
|---|---|---|
| **トークン** | 定着した訳が無い。すべての出典がこの語を使う | 文章をモデルが扱う単位に切ったもの |
| **プロンプト** | 「指示文」では、文脈として渡すものを含まない | モデルに渡すテキスト全体 |
| **エージェント** | 「代理」では意味が変わる | 道具を使って作業を進めるAI |
| **スキル** | 製品の機能名である。言い換えると仕様を指せない | 必要なときだけ読み込まれる指示のまとまり |
| **チャンク** | 「断片」でも通じるが、出典との対応が取れなくなる | 文書を切り分けた一片 |

## 言い換える語

**日本語のほうが正確か、同じくらい通じる語である。**

| 使わない語 | 使う語 | 理由 |
|---|---|---|
| コンテキストウィンドウ | **文脈窓** | 「窓」で意味が通る。定着した訳がある |
| ハルシネーション | **作り話** | 「幻覚」より正確である。実際に起きているのは、無いものを作ることである |
| プログレッシブディスクロージャー | **段階的な開示** | 長く、読みにくい |
| ベストプラクティス | **良い書き方**、**指針** | 中身を言ったほうが短い |
| ガードレール | **歯止め** | 通じる |
| ディスカバリー | **選ばれること** | 何が起きるかを言ったほうが分かる |
| コンテキストエンジニアリング | **渡す情報を選ぶこと** | 訳が定着していない |

## この別冊での実際

**この別冊は、上の判断に従っている。** ただし完全ではない。

| 語 | 使用回数 | 扱い |
|---|---|---|
| スキル | 多い | 残した。製品の機能名である |
| トークン | 中くらい | 残した |
| プロンプト | 少ない | 残した |
| エージェント | 少ない | 残した |
| 文脈窓 | 1回 | 言い換えた |

**「文脈窓」の使用が1回しかないのは、この語をほとんど使わずに書けたためである。** 「渡す量」「入力の長さ」で足りる場面が多かった。

**言い換えるより、その語を使わずに書けないかを先に考える。** これが最も良い解である。

## 依頼者の好みについて

**この標準の依頼者は、横文字を嫌うと明言している。** その好みは、上の判断と多くの場面で一致する。

**一致しない場面が1つある。** 検索される語を言い換えると、AIから見つけてもらえなくなる。

**そのため、この別冊は「横文字を避ける」ではなく「その語を使わずに書けるか先に考え、書けないなら残して説明を添える」を採っている。**

根拠は `AD-05` と、その裏づけである `SRC-AIEXT-008`（A-2。NoLiMa）である。

## 表記のゆれを作らない

<!-- doclint-disable term_consistency -->

**残すと決めた語は、1つの書き方に固定する。**

| 使う | 使わない |
|---|---|
| ユーザー | ユーザ |
| サーバー | サーバ |
| フォルダー | フォルダ |

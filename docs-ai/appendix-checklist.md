# 付録 チェックリスト

**手元に1枚置くためのものである。** 規則の全文は各章にある。

## AIが読む文書を書いたとき

| # | 確かめること | 規則 |
|---|---|---|
| 1 | **その節だけを切り取って人に見せて、答えられるか** | `AD-01` |
| 2 | 見出しに製品名・機能名・答える問いが入っているか | `AD-02` |
| 3 | 節をまたいで「これ」「前者」「上記の」を使っていないか | `AD-03` |
| 4 | 各節の答えが、その節の先頭にあるか | `AD-04` |
| 5 | 同じものを2通りの語で書いていないか | `AD-05` |
| 6 | 廃止した記述が、生きている記述の近くに無いか | `AD-06` |
| 7 | 誤りの文言が、出力されるとおりに書いてあるか | `AD-07` |
| 8 | 図だけに情報を持たせていないか | `AD-09` |
| 9 | 時点に依存する語を使っていないか | `AD-10` |

## AIへの指示書を書いたとき

| # | 確かめること | 規則 |
|---|---|---|
| 1 | 人向けの README と分けてあるか | `AN-01` |
| 2 | 決まった名前・場所に置いてあるか | `AN-02` |
| 3 | **200行以内か** | `AN-04` |
| 4 | **守ったかどうかを機械的に確かめられるか** | `AN-05` |
| 5 | 矛盾した記述が無いか | `AN-06` |
| 6 | 常に要るものだけを置いているか | `AN-08` |
| 7 | AIが既に知っていることを書いていないか | `AN-09` |
| 8 | **必ず守らせたいことを、仕組みで止めているか** | `AN-11` |

## スキルや道具の説明文を書いたとき

| # | 確かめること | 規則 |
|---|---|---|
| 1 | 「何をするか」と「いつ使うか」の両方があるか | `AK-01` |
| 2 | 「いつ使わないか」があるか | `AK-01` |
| 3 | 名前が具体的か（`search`、`helper` でないか） | `AK-02` |
| 4 | **似た説明文の道具が他に無いか** | `AK-02` |
| 5 | 道具の数を絞ってあるか | `AK-03` |
| 6 | 使わないものを後から読み込ませているか | `AK-04` |
| 7 | **新人が読んで使えるか** | `AK-05` |
| 8 | 三人称で書いてあるか | `AK-06` |

## AIに書かせた文書を受け取ったとき

| # | 確かめること | 規則 |
|---|---|---|
| 1 | 主張ごとに出典が書いてあるか | `AV-01` |
| 2 | **すべての数値について、原文を開いたか** | `AV-02` |
| 3 | **すべての固有名詞について、原文を開いたか** | `AV-02` |
| 4 | 「無い」ことの確認を、AIに任せていないか | `AV-03` |
| 5 | 未検証であることが文書に書いてあるか | `AV-04` |
| 6 | **検証していない範囲を書いたか** | `AV-07` |

## 最後に必ずやること

| # | 確かめること |
|---|---|
| 1 | **誤った節をわざと渡して、AIが「わからない」と答えるか試す** |
| 2 | **使う予定のモデルすべてで試す。モデルによって失敗の仕方が違う** |

**この2つを飛ばすと、上のすべてを守っても壊れていることがある。**

手順は [付録 実験の記録](appendix-experiments.md) にある。

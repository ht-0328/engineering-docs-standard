## なぜ別冊なのか

**本編の標準は、人が読む文書だけを扱っている。**

人向けの規則の多くは、AI相手にもそのまま効く。用語を統一する、曖昧な語を数値に置き換える、結論を先に書く。これらは両方に効く。

**しかし、理由が違う。そして、効き方の強さも違う。**

| 規則 | 人に効く理由 | AIに効く理由 |
|---|---|---|
| 用語を統一する | 読み違えを防ぐ | **語が一致しないと、そもそも見つけてもらえない** |
| 結論を先に書く | 走査する読者が拾える | **真ん中に埋めた情報は読み落とされる** |
| 各節を自己完結させる | 拾い読みできる | **文書は切り分けられて渡される。前の節は渡らない** |

さらに、**人向けの規則には無い規則**が要る。矛盾した指示の扱い、常に読まれる部分と読まれない部分の分け方、道具の説明文の書き方などである。

そのため、本編を書き換えるのではなく、別冊を立てた。決めた理由は [ADR-003](../docs/adr/ADR-003-ai-volume.md) にある。

## 3行で

1. **AIは文書を最初から順に読まない。** 切り分けられた一部だけが渡される。だから**節はそれだけで意味が通らなければならない。**
2. **長く渡すほど正答率が落ちる。** ある査読つきの研究では、32,000トークンで13モデル中11モデルが、短い入力での成績の半分を下回った。
3. **AIは矛盾を見つけても質問してこない。** 黙ってどちらかを選ぶ。だから**書いた側が矛盾を残さない**しかない。

## 根拠の作り方

本編と同じ基準を使う。**独立した3出典以上が直接支持するものだけを中核にする。**

ただし、AIの分野には本編に無い事情が2つある。そのため、基準を2つ足した。

### 足した基準1: ベンダーの文書どうしは独立と数えない

Anthropic、OpenAI、Google の文書は、互いに引用していなくても、**同じ利害を持つ。** 「自社のモデルをこう使うと良い」という立場である。

そのため、**ベンダー文書は何社集まっても2出典分として数える。** 3出典目には、査読つきの研究か、公開仕様か、自分で測った結果のいずれかが要る。

### 足した基準2: 自分で測った結果を出典として使う

この分野は測れる。**測れるものは測った。**

実験の記録は [付録 実験の記録](appendix-experiments.md) にある。生の結果は [research/experiments/](../research/experiments/) にある。**同じ手順で再実行できる形にしてある。**

## この別冊は古くなる

**本編より速く古くなる。** 根拠の多くが、変わり続ける製品の仕様だからである。

| 根拠の種類 | 古くなる速さ |
|---|---|
| 査読つきの研究（`SRC-AIEXT-008`） | 遅い。測定条件が書かれているため、後から読み直せる |
| 公開仕様（`SRC-AIEXT-004`、MCP） | 中くらい。版が管理されている |
| ベンダーの製品文書 | **速い。数か月で変わる** |
| 自分で測った結果 | **速い。モデルが変われば結果も変わる** |

そのため、次の2つを決めている。

1. **各ルールに、根拠の種類が分かる出典IDを必ず付ける。** 速く古くなる根拠だけのルールは、それと分かる。
2. **次の確認期限を冒頭に書く。** 期限が来たら、製品文書に由来するルールを1件ずつ確かめ直す。

**期限を過ぎた別冊は、読む前にまず疑う。**

## この別冊自身が守っていること

**AIに読ませる標準が、AIに読めないなら意味がない。**

| ルール | この別冊での実装 |
|---|---|
| `AD-01` 節を自己完結させる | 各章の各節は、その節だけを読んで意味が通るようにしている |
| `AD-02` 見出しを具体的にする | 「概要」「注意」を使わず、何の話かを見出しに入れている |
| `AD-05` 用語を統一する | 「文脈窓」「トークン」など、揺らす語を [付録 横文字の扱い](appendix-loanwords.md) に固定した |
| `AV-01` 出典を必ず示す | すべてのルールに出典IDを付けている |

## 守れていないこと

**正直に書く。**

| 問題 | 状況 |
|---|---|
| **日本語で測った研究が1件も無い** | 引用した査読つき研究はすべて英語である。日本語で同じ結果になる保証は無い。**自分の実験だけが日本語である** |
| 実験が1件しかない | 実験1（節の自己完結）だけを実施した。指示書の長さと曖昧語の効果は測れていない |
| 実験のモデルが限られる | 手元の道具で呼べるモデルだけで測った。ここに無いモデルでは違う結果になりうる |
| ベンダー文書への依存が残る | スキルと道具の章（04）は、根拠の大半がベンダー文書である。査読つきの裏づけが無い |

**これらの穴を埋める手順は [research/further-reading.md](../research/further-reading.md) にある。** 優先順は「本を買う」ではなく、**すでに手元にある3冊の未読の章を読むこと**と、**測っていない2件の実験をやること**である。

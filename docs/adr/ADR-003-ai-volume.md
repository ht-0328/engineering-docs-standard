# ADR-003 AI向けの規則を、本編ではなく別冊にする

| 項目 | 内容 |
|---|---|
| 状態 | 決定 |
| 決定日 | 2026-08-31 |
| 決定者 | このリポジトリの保守担当 |
| 関連 | [docs-ai/index.md](../../docs-ai/index.md)、[research/cross-reference-ai.md](../../research/cross-reference-ai.md) |

**決定**: AI向けの規則は `docs-ai/` に別冊として置く。**本編（`docs/`）は変更しない。**

## 状況

この標準は、人が読む文書だけを扱っている。`docs/01` から `docs/10` と `templates/` の全体を調べたが、**AIやLLMを読者として想定した記述は一件も無い。**

いま多くの仕事はAIにさせる。AIに読ませる文書、AIへの指示書、AIに書かせた文書の確かめ方には、人向けとは違う規則が要る。

## 検討した案

| 案 | 内容 |
|---|---|
| A | 本編に章を足す（`docs/11` 以降） |
| B | **別冊にする（`docs-ai/`）** |
| C | 本編の各章に「AIが読む場合」の節を挿し込む |

## 決定の理由

**案Bを選んだ。** 理由は3つである。

### 1. 古くなる速さが違う

本編の根拠は、書籍4冊と公開標準6件である。**10年単位で変わらない。**

別冊の根拠は、その半分がベンダーの製品文書である。**数か月で変わる。**

| 根拠の種類 | 古くなる速さ |
|---|---|
| 本編の出典（書籍・公開標準） | 遅い |
| 別冊の査読つき研究 | 遅い |
| 別冊のベンダー製品文書 | **速い** |
| 別冊の実測結果 | **速い。モデルが変われば変わる** |

**混ぜると、本編まで「古いかもしれない」と疑われる。** 別冊なら、別冊だけに再確認の期限を持たせられる。実際、別冊の冒頭には次の確認期限（2027-02-28）を書いている。

### 2. 根拠の基準が違う

本編は「独立した3出典以上が直接支持するもの」を中核にしている。

別冊はこの基準を維持したうえで、**2つ足している。**

| 足した基準 | 内容 |
|---|---|
| 1 | **ベンダー文書は、合わせて2出典分までとして数える。** 互いに引用しなくても、同じ利害を持つため |
| 2 | **自分で測った結果を出典として数える。** この分野は測れる |

**本編にこの基準を持ち込むと、本編の出典の数え方が変わってしまう。** 別冊なら、別冊の中だけで完結する。

### 3. 案Cは読みにくくなる

案C（各章に節を挿し込む）は、一見よさそうに見える。**しかし、人向けの規則とAI向けの規則は、同じことを言っていても理由が違う。**

| 規則 | 人に効く理由 | AIに効く理由 |
|---|---|---|
| 用語を統一する | 読み違えを防ぐ | **見つけてもらえない** |
| 結論を先に書く | 走査する読者が拾う | **真ん中が読み落とされる** |

**理由が違うものを同じ節に並べると、どちらの読者にとっても長くなる。** 別冊なら、それぞれの読者に必要な理由だけを書ける。

**この判断は、この別冊自身の規則（`AH-03`）と一致している。** AI向けに足したい記述が全体の2割を大きく超える場合は分ける、としている。

## 決めなかったこと

**本編と別冊を将来まとめるかどうかは決めない。**

AI向けの規則が安定し、ベンダー文書への依存が減れば、本編に取り込む判断はありうる。**その判断は、別冊の再確認期限（2027-02-28）のときに行う。**

## 影響

| 対象 | 影響 |
|---|---|
| `docs/` | **規則は変更しない。** [docs/index.md](../index.md) の章の一覧に、別冊への導線を1行だけ足す |
| `templates/` | **変更しない** |
| `.doclint.yml` | 検査対象に `docs-ai/**` と `templates-ai/**` を足す |
| `tools/build_site.py` | 入力先と出力先を引数で受けられるようにする。**引数なしの動きは変えない** |
| `README.md` | 別冊への導線を足す |
| `CHANGELOG.md` | 本編と別冊で版番号を分ける |
| Zensical 版 | **対象外にする。** 比較用の試験であり、二重に作る必要は無い |

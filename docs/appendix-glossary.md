# 用語集

この標準で使う語の定義である。**この標準自身が「一つの概念には一つの語を使う」（S-10）を守るための台帳でもある。**

`doc_lint` の `term_consistency` は、ここで正とした語と、その揺れを突き合わせる。

## この標準の中心となる語

| 語 | 定義 |
|---|---|
| **良い文書** | 読者が必要な判断と行動を、最小の労力で、正しく行える文書 |
| **品質6軸** | 有用性・発見容易性・正確性・明確性・一貫性・保守性の6つ。文書の質を見るときの観点 |
| **機能的品質** | 正確さ、完全さ、一貫性など、現実と突き合わせて客観的に測れる品質（`SRC-EXT-004`） |
| **深い品質** | 使っていて気持ちがよい、流れがある、といった測れない品質（`SRC-EXT-004`） |
| **一文一義** | 1つの文に1つの主題だけを書くこと |
| **結論先出し** | 結論・推奨案・結果を最初に置き、理由・根拠・詳細を後に置く書き方 |
| **走査** | 読者がページを最初から順に読まず、見出しや強調を拾って目的の箇所を探す読み方 |
| **文書の型** | Tutorial / How-to guide / Reference / Explanation の4分類（`SRC-EXT-004`） |
| **規範度** | ルールの強さ。必須 / 推奨 / 任意の3段階（`SRC-EXT-006`） |
| **出典ID** | `SRC-WRITE-001` のような、参照元を指す安定した識別子 |

## 文書の型（原語のまま使う）

**訳語を作らない。** 読者がこの語で検索するため、原語のまま使う（S-11 の判断による）。

| 語 | 定義 |
|---|---|
| **Tutorial** | 何も知らない学習者に、技能を身につけさせる文書 |
| **How-to guide** | ある程度知っている読者に、目の前の問題を解決させる文書 |
| **Reference** | 作業中の読者に、事実を正確に引かせる文書 |
| **Explanation** | 学習中の読者に、背景と設計思想を理解させる文書 |

## レビューで使う語

| 語 | 定義 |
|---|---|
| **推敲** | 書き手が自分で見直すこと。レビューの前に行う |
| **レビュー** | 第三者が確認すること（`SRC-WRITE-003` 3.7） |
| **Blocker** | 誤った作業を招く、事実が誤っている、判断に必要な情報が欠けている。必ず止める |
| **Major** | 主要な読者が目的を達成できない、構成が破綻している。修正後に再レビュー |
| **Minor** | 限定的な不備。明確性や保守性の不足 |
| **Note** | 将来の改善、質問、参考情報。判定を妨げない |

## 表記の語（`SRC-EXT-003` の定義に従う）

| 語 | 定義 |
|---|---|
| **敬体** | ですます調 |
| **常体** | である調 |
| **体言止め** | 名詞で終わる書き方。見出しに使う |
<!-- doclint-disable-next-line term_consistency -->
| **表記ゆれ** | 同じ語が複数の書き方で現れること（サーバ／サーバー など） |
| **長音** | カタカナ語の末尾の「ー」。JTFは原則として省略しないとする |

## 用語の統一（正とする語）

**左が正である。** 右の語は使わない。

| 正 | 使わない |
|---|---|
| ユーザー | ユーザ、エンドユーザ |
| サーバー | サーバ |
| メモリー | メモリ |
| コンピューター | コンピュータ |
| ドライバー | ドライバ |
| フォルダー | フォルダ |
| プリンター | プリンタ |

**根拠**: `SRC-EXT-003` の基本ルール5「カタカナ語の語尾の長音は省略しない」。

**ただし、JTF自身が業界による揺れを認めている。** 重要なのは、どちらを選ぶかではなく、**同一文書内で統一すること**である。既存の文書が省略する側で統一されているなら、そちらを守る。

## ひらがなで書く語

`SRC-EXT-003` 2.2.1 の一覧から、この標準で使う分を抜き出した。**常用漢字表にあってもひらがなで書く。**

| ひらがな | 使わない |
|---|---|
| あらかじめ | 予め |
| いずれ | 何れ |
| およそ | 凡そ |
| かえって | 却って |
| ください（補助動詞） | 下さい |
| こと（形式名詞） | 事 |
| さらに | 更に |
| しかし | 然し |
| しばらく | 暫く |
| すなわち | 即ち |
| ただし | 但し |
| ため | 為 |
| できる | 出来る |
| どこ | 何処 |
| なお | 尚 |
| または | 又は |
| むしろ | 寧ろ |
| めったに | 滅多に |
| もしくは | 若しくは |
| もはや | 最早 |
| よほど | 余程 |

## 品詞で使い分ける語

| ひらがな | 漢字 | 使い分け |
|---|---|---|
| および | 及ぶ | 接続詞はひらがな、動詞は漢字 |
| したがって | 従う | 接続詞はひらがな、動詞は漢字 |
| いたします | — | 補助動詞はひらがな |
| 〜とおり | 〜通り | 形式名詞はひらがな、数詞に付くときは漢字 |
| 〜とき | 時 | 形式名詞はひらがな、名詞は漢字 |
| ほしい | 欲しい | 補助動詞はひらがな、本動詞は漢字 |
| 〜つく、〜つき | 付く | 接尾語はひらがな、動詞は漢字 |

## 使わない語

**曖昧で、読者ごとに解釈が変わる語である。** 使うときは、具体的な内容に置き換える。

<!-- doclint-disable vague_words timeless -->

| 使わない語 | 置き換える先 |
|---|---|
| 適切に、適宜、必要に応じて | 具体的な条件と手順 |
| 速やかに、なるべく早く、極力 | 年月日と時刻 |
| 十分に、しっかりと、きちんと | 数値と判定方法 |
| 大量の、多数の | 数値と単位 |
| 現在は、今のところ、今後 | 日付、または版数 |
| エビデンス | 証跡（ログ・画面）または根拠（測定値） |
| 巻き取る、握る、なるはや | 具体的な動作と期限 |
